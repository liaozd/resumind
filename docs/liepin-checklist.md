# 猎聘适配器 · 真页核对清单

> spec/site-adapter 纪律：**任何站点的选择器未经真实登录页人工核对，真投通道不得启用**。
> 本清单是写 `src/sites/liepin.js` 的前置条件。请在真实登录的猎聘页面逐项核对并回填；
> 全部核对通过（8.3 用户确认）后解锁真投通道。

## 核对方法

登录猎聘 → 打开职位搜索结果页 → F12 逐项确认下方选择器（改版后类名可能不同，以实际 DOM 为准）。
每项回填格式：`✅/❌ 实际选择器/形态 + 备注（日期）`。

## A. 列表页

| # | 核对项 | 预期形态（参照 BOSS直聘） | 回填 |
|---|---|---|---|
| A1 | 职位卡片容器 | `li.job-card-box`（BOSS） | |
| A2 | 卡片内职位名链接 | `a.job-name`，href 含职位唯一 id | |
| A3 | 唯一 id 形态 | 加密 id 出现在 href 的哪一段？截取哪段做去重键？ | |

| A5 | 搜索路径形态 | 是否存在多种路径形态（BOSS 有单复数两种）？ | |
| A6 | 推荐流/默认列表 | 无 query 时页面行为（v2 是否需要等价物）？ | |

## 回填完成后的流程

1. 回填结果贴给 agent → 写 `src/sites/liepin.js` + 产出 `release/liepin_batch.user.js`（任务 8.2）；
2. 猎聘产物默认**真投通道关闭**，仅采集+判定演练；
3. 用户在真实页面演练验证采集与判定正常（8.3 前半）；
4. 用户显式确认 → 解锁真投通道 → 测试场景更新（8.3 后半）。
